Hent Hub AI

Tre måder: lad den køre af sig selv på en server, hent koden, eller læg dashboardet på telefonens hjemmeskærm.

1 · Installér på din server Anbefalet

Så kører alt døgnet rundt uden, at du skal gøre noget: starter ved boot, genstarter botter, der går ned, og opdaterer sig selv.

  1. Log ind på din serverMed SSH, som du plejer. Det kræver Linux (Ubuntu), Python 3.11 eller nyere og git.
  2. Kør installationenÉn kommando. Scriptet sætter alt op og skriver adressen og en adgangskode ud til sidst.
    git clone https://github.com/Dani-gh1/Hub-AI.git && cd Hub-AI && ./deploy/install.sh
  3. Åbn dashboardetGå til forsiden, skriv serverens adresse, og du er inde.

Glemt adgangskoden? Den står i filen /etc/hub.env på serveren.

2 · Hent koden

Til at prøve den på en Mac eller Linux-computer. Computeren skal være tændt, for at botterne kører.

⬇ Download .zip Hele programmet, ca. 1 MB.
Se på GitHub
Så kører du den
cd Hub-AI python3 -m hub fetch python3 -m hub run

Åbn derefter http://127.0.0.1:8080.

3 · Læg den på hjemmeskærmen

Dashboardet er bygget til telefonen: egen app-ikon, ingen browserlinje og en menu i bunden.

  1. Åbn dit dashboard i SafariBrug den adresse, du gemte på forsiden. Det skal være Safari, ikke en anden browser.
  2. Tryk på Del-knappenFirkanten med pilen op, nederst på skærmen (eller øverst på iPad).
  3. Vælg “Føj til hjemmeskærm”Rul lidt ned i listen, hvis du ikke kan se den. Tryk Tilføj.
  1. Åbn dit dashboard i ChromeBrug den adresse, du gemte på forsiden.
  2. Tryk på menuen ⋮De tre prikker øverst til højre.
  3. Vælg “Føj til startskærm” eller “Installér app”Bekræft med Tilføj. Ikonet ligger nu mellem dine andre apps.
  1. Chrome eller EdgeTryk på installér-ikonet yderst til højre i adresselinjen, eller menu → “Gem og del” → “Installér som app”.
  2. Safari på MacArkiv → Føj til Dock.

Ligger serveren bag Tailscale, skal Tailscale være tændt på telefonen, for at appen kan åbne.
